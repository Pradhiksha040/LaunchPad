# 🔌 LaunchPad OS Integration Hub Guide

The **Integration Hub** is an API Orchestration and Transformation Layer that allows enterprises to connect LaunchPad OS frontend portals directly to legacy enterprise backends (SAP, Oracle, Salesforce, Microsoft Dynamics, REST, GraphQL, SOAP).

---

## 🚀 How Integration Hub Works

1. **Tenant Identification**: On every API request, LaunchPad identifies the tenant via `X-Tenant-ID` header or domain.
2. **Connector Resolution**: LaunchPad queries `TenantConfig` from the DB to select the appropriate connector (`SAPConnector`, `SalesforceConnector`, `GenericRestConnector`).
3. **Payload Transformation**:
   - **Outbound**: Converts LaunchPad Canonical JSON -> Enterprise API Payload.
   - **Inbound**: Converts Enterprise API Response -> LaunchPad Canonical JSON.
4. **API Communication**: Dispatches the request via HTTP/REST/OData/SOAP with exponential retry policy.

---

## 📝 2-Way Payload Mapping Example (SAP Integration)

### LaunchPad Canonical Customer Input
```json
{
  "firstName": "Apollo",
  "lastName": "Patient",
  "email": "patient@apollohospital.org",
  "taxId": "GSTIN99021"
}
```

### Transformed SAP S/4HANA Payload (Generated by SAPConnector)
```json
{
  "NAME_FIRST": "Apollo",
  "NAME_LAST": "Patient",
  "SMTP_ADDR": "patient@apollohospital.org",
  "STCD1": "GSTIN99021",
  "SAP_CLIENT": "100"
}
```
