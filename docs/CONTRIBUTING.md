# 🤝 Contributing to LaunchPad OS

Thank you for contributing to LaunchPad OS! Please follow these branch naming and Git workflow conventions.

---

## 🌿 Git Branching Strategy

- `main` / `master`: Production releases.
- `develop`: Integration branch for active feature development.
- `feature/<name>`: New feature implementations (e.g. `feature/sap-rfc-connector`).
- `bugfix/<name>`: Bug fixes (e.g. `bugfix/jwt-expiration-handler`).

---

## ✏️ Commit Conventions

Follow the Conventional Commits specification:

- `feat: add SAP S/4HANA OData connector`
- `fix: resolve RBAC permission guard bypass`
- `docs: update API reference for canonical endpoints`
- `test: add unit test for ConnectorRegistry`
